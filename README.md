# 🍕 Pizza Sales Analysis

## 📌 Project Overview
This project analyzes pizza sales data using SQL and Power BI to identify sales trends, measure business performance, and generate actionable insights.

---

## 🛠 Tools Used
- MySQL
- Power BI

---

## 📊 KPIs Analyzed
- Total Revenue
- Average Order Value
- Total Orders
- Total Pizzas Sold
- Average Pizzas Per Order

---

## 📈 Analysis Performed

### Data Preparation
- Converted order date into proper DATE format
- Cleaned and transformed dataset for analysis

### Trend Analysis
- Orders by Day
- Orders by Month

### Category Analysis
- Percentage of Sales by Category
- Total Quantity Sold by Category

### Product Analysis
- Top 5 Pizzas by Revenue
- Bottom 5 Pizzas by Revenue
